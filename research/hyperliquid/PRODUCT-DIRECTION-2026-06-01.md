## 3. Token（後置，只在 trigger）— $100M optionality

$100M 的形狀：把驗證去中心化成 **Proof-of-Performance Oracle**（"Chainlink for trading agents，驗的是真實力不是價格"）。$PROOF = attestor 質押才能簽認證 + 簽假被 slash + 讀取方按查詢付費 + fee 回購。
- **TRIGGER（沒到不准發）**：API **≥ $1-2M ARR 且 ≥50 個外部付費 attestor**，單一公司簽章成信任瓶頸時才去中心化。此時 token = 真 fee 撐（Hyperliquid 模型 fee→buyback），是已驗證需求的放大器，不是賭注。

## 4. 誠實護欄（devil's advocate 給 token-trap 8/10）

- 現在 token-first = 負 EV，會變死 meme。**順序不可逆：先現金產品 → 到 trigger 才發幣。** 這正是你說的「現金 now、$100M later、不急」。
- **發任何 token 前必答 3 題**：
  1. **沒有 token，這 API 能不能到 $1M ARR？** 不能 → token 只是掩蓋「沒人付費」（又一次 over-build 未驗證需求）。
  2. **token 持有者現金流哪來、可審計嗎？**（寫不出「fee X% → 回購/分潤，鏈上可查」就是敘事幣，必歸零）
